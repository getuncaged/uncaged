# Uncaged 0.3.3

Splits get a proper home: every pane is its own card, tabs can be split and
arranged from their menu, and the rounded look from 0.3.2 reaches the surfaces
it had missed.

## Splits

- **Each pane in a split is its own rounded card**, with a gap between panes.
  The resize handle lives in the gap and shows a seam on hover.
- **Split and arrange from the tab menu.** Split adds a pane on any side;
  Arrange lays a tab's panes out side by side, as one large pane with the rest
  stacked, or as a grid, or unsplits them into separate tabs. Other tabs get
  rows to join the current tab as a split.
- **Drag a tab onto the panes** to split it there: a preview shows the half of
  the hovered pane it will take. Dragging it off the window still opens it in a
  new window.
- **Open a conversation in a split pane** from its menu.
- Pane header buttons show only while you hover the header, so a screen of
  splits isn't a grid of identical controls. New split panes skip the "New
  terminal session" welcome card.
- **The mode switch is lit only in the focused pane.** Other panes still show
  their current mode (terminal or agent) in its colour, without the fill, and
  the highlight follows focus as soon as you click another pane.

## Conversation list

- One line per conversation: a status dot while it is running, blocked or
  failed, the title, and a short age. The directory and status are in the
  tooltip.
- Sections read **Active** and **Recent**, and **New conversation** is a +
  beside the search field.

## Polish

- Tab titles that don't fit end in an ellipsis instead of being cut from the
  front; titles that look like paths keep their end.
- Editor: the current line and diff highlights are rounded bands, file tabs are
  rounded, and file names are no longer clipped from the left. The code pane's
  footer follows the pane's rounded corners.
- The workflow card, history menu, slash-command menu and other inline menus
  are rounded cards lined up with the input.
- "New terminal session", the agent welcome block, shortcuts, queued prompts
  and inline banners are rounded cards instead of bands between rules.
- The "Previous session" band no longer appears under an empty pane, and lines
  up with the input box.
- Hint rows drop a hint that doesn't fit instead of cutting it mid-word.

## Upgrading

Homebrew: `brew upgrade --cask uncaged`. winget: `winget upgrade Uncaged.Uncaged`
once the new version is accepted. Otherwise download the package for your
platform below; on macOS, clear the quarantine flag on first launch as described
in the README.
