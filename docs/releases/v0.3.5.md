# Uncaged 0.3.5

Uncaged is now its own app: the Warp account, cloud and telemetry code is
gone, the download is a third smaller, and an idle window costs about as much
as a plain terminal.

## Light on your machine

- **Nearly silent when idle.** An idle, focused window used about 0.4% CPU;
  it now uses about 0.01%. The input cursor stops blinking 10 seconds after
  your last keystroke (it used to redraw the whole window twice a second
  forever), an unused 5-second stats poll is gone, file watchers no longer
  wake up every half second, and git prompt chips don't run `git` while
  Uncaged is in the background.
- **Less memory.** About 150 MB for an idle window after a minute, down from
  about 290 MB; with 30 restored tabs, about 305 MB instead of 440 MB.
  Rendering reuses its GPU buffers instead of allocating new ones every frame.
- **Fewer threads.** Background work runs on 2 to 6 threads instead of one
  per CPU core.
- **Heavy output stays cheap.** Output is parsed in batches, so a flood of
  lines spends less time on bookkeeping. On macOS the terminal now keeps up
  with what the system's PTY can deliver.
- **Smaller download.** The app binary is about half its previous size and
  the macOS DMG is about 92 MB, down from 137 MB.

## Uncaged's own identity

- The app is now **`uncaged`** with bundle id **`dev.uncaged.Uncaged`** (it was
  `warp-oss` / `dev.uncaged.WarpOss`). The first launch moves your settings,
  history, Drive and sessions to the new name and leaves a link behind, so
  going back to 0.3.4 still finds them. `~/.uncaged` is not touched.
- **No Warp account layer, telemetry, crash reporting, cloud sync, shared
  sessions or cloud agents.** The code that talked to Warp's servers is
  removed, not just switched off. Drive is local: creating, editing, trashing
  and restoring objects all happen on this machine.
- **Uncaged never starts at login** and removes the login item older builds
  added.

## Tabs

- **Grouped tabs (macOS) and pinned tabs** are on. A group is a small chip
  with its name and a thin line in the group's color under its tabs; open
  groups get a soft glow, and tabs can be dragged out of a group.
- New tabs open at the end of the bar (or just past the current tab's group),
  instead of joining the active tab's group. **New tab in group** adds one
  explicitly.
- Every tab has the same plain close button.

## Blocks and input

- **One-line command headers.** A finished block reads like a classic shell:
  the prompt, then the command on the same row. Long or multi-line commands
  keep the prompt above them. A clean tree's "0 • +0 -0" is left out, and
  durations show only for commands that took a second or more.
- If your shell waits for input while starting (an Oh My Zsh update prompt,
  for example), the slow-start banner now says so and points at the block
  where you can answer it.
- A file tab whose file was moved or deleted says which file, instead of
  "Failed to load file."
- Opening a Docker sandbox without `sbx` installed shows an error instead of
  failing silently.
- The resize cursor fix and a tab-completion autosuggestion tweak that Warp
  never shipped are on.

## Upgrading

Homebrew: `brew upgrade --cask uncaged`. winget: `winget upgrade Uncaged.Uncaged`
once the new version is accepted. Otherwise download the package for your
platform below; on macOS, clear the quarantine flag on first launch as described
in the README. On macOS, 0.3.4's in-app update installs this release; on Linux
and Windows, update the way you installed (the packages upgrade the 0.3.4
install in place).

The Linux packages were attached a few hours after the rest: the release build's
AppImage step still pointed the launcher at the old `warp-oss` binary, and they
were rebuilt with that fixed.
