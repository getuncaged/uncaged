# Uncaged 0.3.1

Brings 0.3.0 to Linux and Windows.

## Fixes

- The Linux and Windows builds of 0.3.0 failed to compile: the update checker
  called a macOS-only function on every platform. 0.3.1 fixes that, so the
  `.deb`, `.rpm`, AppImage, tarball and Windows installers are back.

Nothing else changed. macOS users on 0.3.0 can skip this release. For what's new
in 0.3, including Colin's theme and menu fixes (#36, #37), see the
[0.3.0 release notes](https://github.com/getuncaged/uncaged/releases/tag/v0.3.0).

## Upgrading

Homebrew: `brew upgrade --cask uncaged`. Otherwise download the package for your
platform below; on macOS, clear the quarantine flag on first launch as described
in the README.
