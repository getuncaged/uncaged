# Uncaged 0.3.2

Finishes the rounder, quieter UI from 0.3.0 in the places it had missed.

## Polish

- **Rounded, inset highlights in every picker and list.** The selected or
  hovered row is now a rounded pill set in from the edges, instead of a square
  bar running the full width. This covers the branch and directory pickers, tab
  completion and history, the context menu, the diff and find-references menus,
  the theme chooser, the conversation list, workflows, the SSH, config and
  skills panels, and the vertical-tabs options.
- The thin dividers between rows in those menus are gone; footers keep a single
  rule above them.
- The "Previous session" banner over restored blocks is a rounded band rather
  than a square box with a hard outline.

## Upgrading

Homebrew: `brew upgrade --cask uncaged`. winget: `winget upgrade Uncaged.Uncaged`
once the new version is accepted. Otherwise download the package for your
platform below; on macOS, clear the quarantine flag on first launch as described
in the README.
