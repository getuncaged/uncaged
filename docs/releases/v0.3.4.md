# Uncaged 0.3.4

Your agents can search your code, themes have one home, and Settings is
rebuilt as rounded cards that follow the window.

## Code search, on your machine

- **A local codebase index.** Uncaged indexes the repository you open in a
  terminal and ranks code by keywords and identifiers, entirely on this
  machine: nothing is uploaded and nothing costs money. It is on by default;
  `.uncagedignore` keeps files out, and Settings → Indexing and projects shows
  its status.
- **Claude Code can use it.** CLI agents run their own tools, so Uncaged now
  hands each agent session a private code search tool (`search_codebase`,
  over a local MCP server that only this Mac can reach). The agent calls it
  like any of its own tools; it is approved automatically because it only
  reads the index. Gemini CLI and Codex get it too when their CLI can connect
  to HTTP MCP servers.
- **CLI agents start in your terminal's folder,** so they see the same files
  and project settings you do.

## Themes

- **The theme gallery is the one place to browse and switch themes.** Warp's
  old picker panel is gone; the command palette, shortcuts and tips open the
  gallery instead.
- **A faster gallery.** It no longer downloads anything at startup. The first
  time you open it, it shows the catalogue saved from last time and refreshes
  it once; offline it keeps the saved copy. The grid isn't rebuilt on every
  hover or keystroke, and every card uses a small thumbnail.
- **Choose your light and dark themes by looking at them.** With Sync with OS
  on, Appearance shows the two as preview tiles. Change… opens the gallery to
  pick for that slot, with your own themes included.
- **A redesigned theme creator.** A live preview of the theme you're editing
  sits beside section cards for colors, background, window and appearance.
  The background image now lives in the Background card, and each of the 16
  terminal colors says where you'll see it. **From image** is three guided
  steps: choose an image, pick a background, then fine-tune every color.
- **Share with the community** is the highlighted action in the theme creator;
  it opens a pull request adding your theme to the community gallery.
- The theme creator no longer paints its unsaved theme over the whole app.
  Only Save or Create changes your theme.

## Settings

- **Every settings page is rounded cards** in a panel beside the sidebar that
  grows with the window and reflows down to narrow widths.
- **The sidebar has four labelled groups** (Agents, Code, Look & feel, App)
  with shorter page names. Options that need a Warp account are gone, and each
  toggle has one home.
- **Appearance is reorganised** into Theme, Text, Window, Tabs, Input, Blocks &
  panes, Cursor and Dock, with one column of controls and slider values beside
  their sliders.
- The gear in the tab bar opens Settings, replacing the account avatar.

## Polish

- **A short launch animation:** the Uncaged mark shimmers in over the first
  window while it starts, then fades into your terminal. It never delays
  startup, and you can turn it off in Appearance → Window.
- Your own turns in agent conversations are marked with a `›` instead of a
  placeholder avatar.
- Blocks restored from your last session sit in an inset card under a quiet
  "Previous session" label.

## Upgrading

Homebrew: `brew upgrade --cask uncaged`. winget: `winget upgrade Uncaged.Uncaged`
once the new version is accepted. Otherwise download the package for your
platform below; on macOS, clear the quarantine flag on first launch as described
in the README.
