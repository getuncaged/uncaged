# Uncaged 0.3.0

The split from Warp. 0.3.0 is the first release built from Uncaged's own line
(`uncaged-0.3`) rather than a mirror of upstream Warp with patches on top.

## One input, two modes

- **One input surface** for Terminal mode, Agent mode and agent conversations.
  Switching modes keeps the box, the prompt row, the input line and the toggle
  in place; only the buttons that belong to a mode appear or disappear.
- **The mode is a toggle, not a guess.** Terminal and Agent are a two-segment
  switch (⌘I). Natural-language autodetection is off by default; turn it on with
  the A+ button, and the toggle shows which mode it detected.
- The old prefix tricks are gone: no `!` marker in front of the input, typing `!`
  no longer flips modes, and the "⌘I to exit shell mode" hint is removed.
  (Claude Code's own `!` bash mode inside its CLI input is unchanged.)
- ESC and Ctrl-C no longer throw you out of a mode.

## Models and effort

- **Effort control** in the model chip — `model | Medium effort` — for Anthropic
  (low → max), OpenAI-compatible endpoints (low → high) and Claude Code
  (low/medium/high/max, applied by resuming the session so it keeps its
  context).
- The model menu lists what your provider actually serves (fetched from
  `GET …/models`), so LM Studio and Ollama show your downloaded models.
- Switching Claude Code's model applies to the running session immediately.

## A rounder, quieter UI

- Rounded, consistent corners everywhere (shared small/medium/large radii):
  menus, buttons, inputs, dialogs, toasts, tabs.
- Side panels (files, code review, vertical tabs) are rounded cards; the main
  view becomes a card only when a side panel is open beside it. No more 1px
  rules between panels.
- Settings: rounded sidebar, each category in its own card, and no redundant
  "Settings" title bar when it's the only pane.
- Lighter tab bar; tabs are named after their folder (`~`, `Brain`) instead of
  `user@host:path`.
- New-tab menu lists Terminal first, with distinct Terminal and Agent icons.

## Updates, privacy and performance

- **One-click updates** from GitHub Releases, with the download verified
  against the release checksum; package-manager installs are left alone.
- No login keychain on macOS; the last paths that sent terminal content to
  Warp's servers are removed.
- The app no longer wakes up while idle, launches faster, and stops
  enumerating every system font at startup; the ONNX classifier model is no
  longer shipped.

## Fixes

- If a CLI agent (Claude Code, Codex, …) exits while its input is open, the
  terminal input returns to the mode you were in instead of staying stuck in
  Agent mode.
- Your saved theme is no longer replaced by the default palette after a restart
  (#34, fixed in #36).
- The macOS application menu says "Hide Uncaged" and "Quit Uncaged" instead of
  Warp (#35, fixed in #37).
